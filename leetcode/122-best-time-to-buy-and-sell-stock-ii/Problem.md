# Best Time to Buy and Sell Stock II

- 문제 번호: 122

- 난이도: Medium
- 태그: Array, Dynamic Programming, Greedy

## 문제 설명 (요약)

배열 `prices`가 주어지며, `prices[i]`는 `i`번째 날의 주식 가격이다.

이번엔 [121번 문제](../121-best-time-to-buy-and-sell-stock/Problem.md)와 달리 **거래 횟수 제한이 없다** — 원하는 만큼 여러 번 사고팔아서 얻을 수 있는 **최대 이익**을 구한다. 단,

- 동시에 여러 주를 들고 있을 수 없다 — 다시 사려면 그 전에 반드시 팔아야 한다(같은 날 팔고 다시 사는 것은 가능).
- 총 이익을 최대화하면 된다.

## 제약사항

- `1 <= prices.length <= 3 * 10^4`
- `0 <= prices[i] <= 10^4`

### 입출력 예 설명

**입출력 예 #1**: 2일차(가격 1)에 사서 3일차(가격 5)에 팔면 이익 4, 다시 4일차(가격 3)에 사서 5일차(가격 6)에 팔면 이익 3 — 합쳐서 `4 + 3 = 7`이 최대 이익이다.

**입출력 예 #2**: 1일차(가격 1)에 사서 5일차(가격 5)에 팔면 이익 `4`. (중간에 나눠서 사고팔아도 합은 동일하다.)

**입출력 예 #3**: 가격이 계속 떨어지기만 해서 어떤 조합으로 사고팔아도 이익을 낼 수 없다. `0`을 반환한다.
