# Two Sum

- 문제 번호: 1
- 링크: https://leetcode.com/problems/two-sum/
- 난이도: Easy
- 태그: Array, Hash Table

## 문제 설명 (요약)

정수 배열 `nums`와 정수 `target`이 주어질 때, 두 원소의 합이 `target`이 되는 **두 인덱스**를 반환한다.

- 정답은 항상 정확히 하나 존재한다고 가정해도 된다.
- 같은 원소를 두 번 쓸 수는 없다.
- 반환 순서는 상관없다.

(Follow-up: `O(n²)`보다 빠르게 풀 수 있는가?)

## 제약사항

- `2 <= nums.length <= 10^4`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`
- 정답은 항상 유일하게 존재한다.

## 입출력 예

| nums | target | 결과 |
|---|---|---|
| [2,7,11,15] | 9 | [0,1] |
| [3,2,4] | 6 | [1,2] |
| [3,3] | 6 | [0,1] |

### 입출력 예 설명

**입출력 예 #1**: `nums[0] + nums[1] == 9` → `[0, 1]`

**입출력 예 #2**: `nums[1] + nums[2] == 6` → `[1, 2]`

**입출력 예 #3**: 같은 값(3)이 두 번 있는 경우, 서로 다른 두 인덱스 `[0, 1]`을 반환한다.
