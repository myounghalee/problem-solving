# Add Two Numbers

- 문제 번호: 2
- 링크: https://leetcode.com/problems/add-two-numbers/
- 난이도: Medium
- 태그: Linked List, Math, Recursion

## 문제 설명 (요약)

음수가 아닌 두 정수가 각각 연결 리스트로 주어진다. 각 노드는 숫자 하나(자리 하나)를 담고, **자리수는 역순으로** 저장되어 있다(1의 자리가 head). 두 수를 더한 결과를 같은 방식(역순 연결 리스트)으로 반환한다.

두 입력에 선행 0(맨 앞에 불필요한 `0`)이 있는 경우는 없지만, 숫자 `0` 자체는 노드 하나(`[0]`)로 표현될 수 있다.

## 제약사항

- 각 연결 리스트의 노드 개수는 `1`부터 `100` 사이.
- `0 <= Node.val <= 9`
- 리스트가 나타내는 숫자에 선행 0은 없다(단, 숫자 `0` 자체는 예외).

## 입출력 예

| l1 | l2 | 결과 |
|---|---|---|
| [2,4,3] | [5,6,4] | [7,0,8] |
| [0] | [0] | [0] |
| [9,9,9,9,9,9,9] | [9,9,9,9] | [8,9,9,9,0,0,0,1] |

### 입출력 예 설명

**입출력 예 #1**: `342 + 465 = 807`. 역순 표현이므로 `[2,4,3]`은 `342`, `[5,6,4]`는 `465`이고 결과 `[7,0,8]`은 `807`이다.

**입출력 예 #2**: `0 + 0 = 0`.

**입출력 예 #3**: `9999999 + 9999 = 10009998`. 두 리스트의 길이가 다르고, 자리올림이 맨 끝까지 이어져 결과 리스트가 더 길어지는 경우다.
