# Best Time to Buy and Sell Stock

- 문제 번호: 121
- 링크: https://leetcode.com/problems/best-time-to-buy-and-sell-stock/
- 난이도: Easy
- 태그: Array, Dynamic Programming

## 문제 설명 (요약)

배열 `prices`가 주어지며, `prices[i]`는 `i`번째 날의 주식 가격이다.

**정확히 한 번**만 주식을 사고(어느 하루), 이후 **다른 하루에 한 번**만 팔아서 얻을 수 있는 **최대 이익**을 구한다. 이익을 낼 수 없다면(가격이 계속 떨어지기만 하는 경우 등) `0`을 반환한다.

- 사는 날은 파는 날보다 반드시 앞서야 한다(같은 날 사고파는 것도 불가능하지는 않지만 이익이 0이 되므로 의미 없음).

## 제약사항

- `1 <= prices.length <= 10^5`
- `0 <= prices[i] <= 10^4`

**입출력 예 #1**: 2일차(가격 1)에 사서 5일차(가격 6)에 팔면 이익은 `6 - 1 = 5`로 최대가 된다.

**입출력 예 #2**: 가격이 계속 떨어지기만 해서 어떤 조합으로 사고팔아도 이익을 낼 수 없다. 이익이 없으므로 `0`을 반환한다.
