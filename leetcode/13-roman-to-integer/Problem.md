# Roman to Integer

- 문제 번호: 13
- 링크: https://leetcode.com/problems/roman-to-integer/
- 난이도: Easy
- 태그: Hash Table, Math, String

## 문제 설명 (요약)

로마 숫자는 7개의 기호로 표현된다.

| 기호 | 값 |
|---|---|
| I | 1 |
| V | 5 |
| X | 10 |
| L | 50 |
| C | 100 |
| D | 500 |
| M | 1000 |

기본적으로는 기호 값을 왼쪽부터 순서대로 더하면 되지만(`XII` = `X`+`I`+`I` = 12), 작은 기호가 큰 기호 앞에 오면 **빼야 하는** 경우가 6가지 있다 — `IV`(4), `IX`(9), `XL`(40), `XC`(90), `CD`(400), `CM`(900).

로마 숫자 문자열 `s`가 주어지면, 이를 정수로 변환하여 반환한다. ([12번(Integer to Roman)](../12-integer-to-roman/Problem.md)의 정반대 방향 변환이다.)

## 제약사항

- `1 <= s.length <= 15`
- `s`는 `I`, `V`, `X`, `L`, `C`, `D`, `M`으로만 구성된다.
- `s`는 항상 1~3999 범위의 유효한 로마 숫자임이 보장된다.
