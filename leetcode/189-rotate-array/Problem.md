# Rotate Array

- 문제 번호: 189
- 링크: https://leetcode.com/problems/rotate-array/
- 난이도: Medium
- 태그: Array, Math, Two Pointers

## 문제 설명 (요약)

정수 배열 `nums`가 주어지고, 이 배열을 오른쪽으로 `k`칸 회전시켜야 한다.

배열을 새로 만들어 반환하는 게 아니라, **입력 배열 `nums`를 제자리(in-place)에서 수정**해서 결과를 담아야 한다. 반환값은 없다(void).

## 제약사항

- `1 <= nums.length <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`
- `0 <= k <= 10^5`

### 심화 (Follow up)

- 가능한 한 여러 가지 풀이 방법을 찾아보라 (최소 세 가지 이상의 서로 다른 알고리즘이 존재).
- 추가 공간을 O(1)만 사용하는 in-place 풀이로 풀어보라.

| nums (입력) | k | nums (수정 후) |

### 입출력 예 설명

**입출력 예 #1**: 배열을 오른쪽으로 1칸씩 3번 회전시키면 `[5,6,7,1,2,3,4]`가 된다.

**입출력 예 #2**: 배열을 오른쪽으로 1칸씩 2번 회전시키면 `[3,99,-1,-100]`이 된다.
