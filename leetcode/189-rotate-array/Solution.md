# [LeetCode 189] Rotate Array — 한 칸씩 밀기를 k번 반복하기

- 문제 번호: 189
- 링크: https://leetcode.com/problems/rotate-array/
- 난이도: Medium
- 태그: Array, Math, Two Pointers
- 사용 자료구조/알고리즘: **제자리(in-place) 원소 이동 (브루트포스)**

## 1. 문제 요약

배열 `nums`를 오른쪽으로 `k`칸 회전시켜야 한다. 새 배열을 반환하는 게 아니라 `nums` 자체를 제자리(in-place)에서 수정한다.

```text
예시) nums = [1,2,3,4,5,6,7], k = 3 → nums = [5,6,7,1,2,3,4]
      nums = [-1,-100,3,99], k = 2 → nums = [3,99,-1,-100]
```

## 2. 접근 아이디어

"오른쪽으로 `k`칸 회전"을 한 번에 계산하려 하지 않고, **"오른쪽으로 1칸 회전"을 `k`번 반복**하는 것으로 문제를 쪼갠다.

배열을 오른쪽으로 1칸 회전시킨다는 건 다음과 동작과 같다.

- 맨 마지막 원소(`nums[n-1]`)가 맨 앞(`nums[0]`)으로 이동한다.
- 나머지 모든 원소는 한 칸씩 뒤로 밀린다 (`nums[j]` → `nums[j+1]`).

이걸 배열 하나만 갖고 제자리에서 하려면, 값을 그냥 덮어쓰면 안 되고(원본 값이 사라짐) **"지금 들고 있는 값"과 "그 자리에 원래 있던 값"을 계속 맞바꿔가며 앞에서 뒤로 흘려보내는** 방식을 쓴다.

- `num`에 맨 앞 값(`nums[0]`)을 미리 담아둔다 — 이 값이 결국 맨 뒤로 이동할 값이다.
- `j`를 1부터 끝까지 옮겨가며, `nums[j]`의 원래 값을 `next`에 잠깐 저장해두고, `nums[j]` 자리엔 들고 있던 `num`을 써넣은 뒤, `num`을 `next`로 갱신한다 — 즉 값 하나를 들고 배열을 오른쪽으로 흘려보내는 것이다.
- 루프가 끝나면 `num`에는 원래 `nums[n-1]`이었던 값이 남아있고, 이를 `nums[0]`에 써서 순환을 완성한다.

이 "1칸 회전"을 바깥 루프에서 `k`번 반복하면 원하는 결과가 나온다.

### 손으로 시뮬레이션 — `nums = [1,2,3,4,5,6,7]`, `k = 3`

**첫 번째 회전(`i=0`)의 내부 동작**

| j | num (들고 있던 값) | next = nums[j] | nums[j] = num 이후 배열 | num 갱신 |
|---|---|---|---|---|
| (시작) | `num = nums[0] = 1` | - | `[1,2,3,4,5,6,7]` | 1 |
| 1 | 1 | 2 | `[1,1,3,4,5,6,7]` | 2 |
| 2 | 2 | 3 | `[1,1,2,4,5,6,7]` | 3 |
| 3 | 3 | 4 | `[1,1,2,3,5,6,7]` | 4 |
| 4 | 4 | 5 | `[1,1,2,3,4,6,7]` | 5 |
| 5 | 5 | 6 | `[1,1,2,3,4,5,7]` | 6 |
| 6 | 6 | 7 | `[1,1,2,3,4,5,6]` | 7 |

루프가 끝난 뒤 `nums[0] = num(=7)`을 써주면 `[7,1,2,3,4,5,6]` — 1칸 회전 완료.

**바깥 루프(`i`) 진행에 따른 전체 배열 변화**

| i (몇 번째 회전) | 회전 후 배열 |
|---|---|
| 0 | [7,1,2,3,4,5,6] |
| 1 | [6,7,1,2,3,4,5] |
| 2 | [5,6,7,1,2,3,4] |

`k=3`이므로 3번 회전한 `[5,6,7,1,2,3,4]`가 최종 결과 — 정답과 일치한다.

## 3. 코드 (Java)

```java
class Solution {
    public void rotate(int[] nums, int k) {
        for (int i = 0; i < k; i++) {           // 1칸 회전을 k번 반복
            int num = nums[0];                  // 맨 앞 값을 들고 시작 (결국 맨 뒤로 이동할 값)
            for (int j = 1; j < nums.length; j++) {
                int next = nums[j];              // 이 자리의 원래 값을 잠깐 보관
                nums[j] = num;                    // 들고 있던 값을 한 칸 뒤로 흘려보냄
                num = next;                       // 다음 자리로 넘길 값을 갱신
            }
            nums[0] = num;                       // 맨 마지막에 남은 값(원래 nums[n-1])을 맨 앞으로
        }
    }
}
```

### 코드 설명

- 바깥 `for (i)` 루프는 "오른쪽으로 1칸 회전"을 `k`번 실행하는 역할만 한다. 회전 로직 자체는 안쪽 루프에 있다.
- 안쪽 루프는 `num`이라는 변수 하나에 값을 담아 배열을 오른쪽으로 흘려보내는 방식이다. `nums[j]`를 덮어쓰기 전에 `next`로 미리 원래 값을 저장해두기 때문에, 값을 잃어버리지 않고 제자리에서 이동시킬 수 있다.
- 루프가 끝난 시점의 `num`은 이번 회전에서 맨 앞으로 와야 할 값(직전 회전 결과의 마지막 원소)이므로, `nums[0]`에 대입해 순환을 마무리한다.

## 4. 복잡도 분석

- **시간복잡도**: `O(n * k)` — 1칸 회전(`O(n)`)을 `k`번 반복한다. `k`가 `nums.length`보다 훨씬 클 수 있으므로(제약상 `k`는 `10^5`까지, `nums.length`와 독립적), 최악의 경우 `n`과 `k`가 모두 `10^5`에 가까우면 연산 횟수가 매우 커질 수 있다.
- **공간복잡도**: `O(1)` — `num`, `next` 등 변수 몇 개만 사용하고 추가 배열을 만들지 않는다.

참고로 이 문제는 "가능한 한 여러 방법으로 풀어보라"는 follow-up이 있는데, 이 풀이는 그중 가장 직관적인 브루트포스 방식이다. 회전 횟수를 `k % nums.length`로 먼저 줄이거나, 배열을 세 번 뒤집는(reverse) 방식, 또는 별도 배열에 옮겨 담는 방식 등으로 `O(n)` 시간에 끝내는 최적화도 가능하다.

## 5. 엣지 케이스

- **`k = 0`**: 바깥 루프가 한 번도 안 돌아서 배열이 그대로 유지된다.
- **`k`가 `nums.length`의 배수**(예: `k = n`): `n`번 회전하면 한 바퀴를 다 돌아 원래 배열로 되돌아온다 — 결과는 맞지만 연산은 낭비된다.
- **`k > nums.length`**: 여전히 정답은 맞다(회전은 순환이므로 `k`번이나 `k % n`번이나 최종 배열은 같다), 다만 시간이 `k`에 비례해 늘어난다.
- **`nums.length = 1`**: 안쪽 루프(`j < nums.length`)가 실행되지 않아 `num = nums[0]`을 그대로 `nums[0]`에 다시 써주는 것과 같으므로, `k`와 무관하게 배열이 그대로 유지된다.
