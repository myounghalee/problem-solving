# 3Sum

- 문제 번호: 15
- 링크: https://leetcode.com/problems/3sum/
- 난이도: Medium
- 태그: Array, Two Pointers, Sorting

## 문제 설명 (요약)

정수 배열 `nums`가 주어질 때, **합이 0이 되는 서로 다른 세 수의 조합**을 전부 찾는다. 각 조합은 오름차순 등 순서와 무관하게 값 자체가 중복되지 않아야 하고(같은 조합이 두 번 나오면 안 됨), 같은 인덱스를 두 번 이상 쓸 수는 없다.

## 제약사항

- `3 <= nums.length <= 3000`
- `-10^5 <= nums[i] <= 10^5`

## 입출력 예

| nums | 결과 |

| [-1,0,1,2,-1,-4] | [[-1,-1,2],[-1,0,1]] |
| [0,1,1] | [] |

### 입출력 예 설명

**입출력 예 #1**: `(-1)+(-1)+2=0`과 `(-1)+0+1=0`이 성립하는 두 조합이 나온다. 배열에 `-1`이 두 번 있지만, 조합 자체는 값 기준으로 중복 없이 한 번씩만 나와야 한다.

**입출력 예 #2**: 합이 0이 되는 세 수 조합이 없다.

**입출력 예 #3**: `0`이 세 번 있어 `[0,0,0]` 하나가 답이 된다.
