# Remove Duplicates from Sorted Array II

- 문제 번호: 80
- 링크: https://leetcode.com/problems/remove-duplicates-from-sorted-array-ii/
- 난이도: Medium
- 태그: Array, Two Pointers

## 문제 설명 (요약)

정수 배열 `nums`가 **오름차순으로 정렬**되어 있다. 이 배열에서 같은 값이 **최대 두 번까지만** 나오도록 중복을 제거하고, 그 상대적 순서는 유지해야 한다.

단순히 새 배열을 반환하는 게 아니라, **입력 배열 `nums`를 제자리(in-place)에서 수정**해서 결과를 담아야 한다. 정확히는:

1. `nums`의 원소들을 앞에서부터 "값마다 최대 두 개까지"만 남도록 바꿔 쓴다(나머지 값은 상관없다 — 배열 크기 자체를 바꿀 수는 없으므로 뒤쪽엔 아무 값이 남아있어도 된다).
2. 이렇게 바꾼 뒤 유효한 원소의 개수 `k`를 반환한다.

채점기는 `nums`의 앞 `k`개 원소만 확인하므로, `k` 뒤에 남는 값은 채점에 영향을 주지 않는다.

## 제약사항

- `1 <= nums.length <= 3 * 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums`는 오름차순(non-decreasing)으로 정렬되어 있다.
- **추가 공간은 상수(O(1))만 사용해야 한다.**

## 입출력 예

| nums (입력) | 반환값 k | nums (수정 후, 앞 k개) |
|---|---|---|
| [1,1,1,2,2,3] | 5 | [1,1,2,2,3] |

### 입출력 예 설명

**입출력 예 #1**: `1`이 세 번, `2`가 두 번, `3`이 한 번 등장한다. 각 값을 최대 두 개까지만 남기면 `[1,1,2,2,3]`이 되고, 유효한 길이는 `5`다.

**입출력 예 #2**: `0`은 두 번, `1`은 네 번, `2`는 한 번, `3`은 두 번 등장한다. 각 값을 최대 두 개까지만 남기면 `[0,0,1,1,2,3,3]`이 되고, 유효한 길이는 `7`다.
