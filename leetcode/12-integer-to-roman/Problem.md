# Integer to Roman

- 문제 번호: 12
- 링크: https://leetcode.com/problems/integer-to-roman/
- 난이도: Medium
- 태그: Hash Table, Math, String

## 문제 설명 (요약)

로마 숫자는 7개의 기호로 표현된다.

| 기호 | 값 |
|---|---|
| I | 1 |
| V | 5 |
| X | 10 |
| L | 50 |
| C | 100 |
| D | 500 |
| M | 1000 |

정수를 로마 숫자로 변환할 때는 큰 자릿값부터 순서대로 기호를 이어붙인다. 기본적으로는 뺄 수 있는 가장 큰 값의 기호를 앞에 붙이고 그 값을 빼는 과정을 반복하지만, 각 자릿값이 4 또는 9로 시작하는 경우에는 "감산 표기법"(작은 기호를 큰 기호 앞에 써서 빼는 방식)을 쓴다 — 예를 들어 4는 `IV`(5에서 1을 뺌), 9는 `IX`(10에서 1을 뺌). 감산 표기법은 4, 9, 40, 90, 400, 900(`IV`, `IX`, `XL`, `XC`, `CD`, `CM`)에만 쓰인다.

10의 거듭제곱 기호(`I`, `X`, `C`, `M`)는 같은 자릿수를 나타내기 위해 최대 3번까지만 연속으로 쓸 수 있고, `V`/`L`/`D`는 여러 번 반복해서 쓸 수 없다(4번 반복해야 하는 상황이면 반드시 감산 표기법을 쓴다).

정수 `num`이 주어지면, 이를 로마 숫자 문자열로 변환하여 반환한다.

## 입출력 예

| num | 결과 |
|---|---|
| 3749 | "MMMDCCXLIX" |
| 58 | "LVIII" |
| 1994 | "MCMXCIV" |

### 입출력 예 설명

**입출력 예 #1 (`num = 3749`)**
- 3000 = `MMM` (1000×3)
- 700 = `DCC` (500 + 100×2)
- 40 = `XL` (50에서 10을 뺌)
- 9 = `IX` (10에서 1을 뺌)
- 참고: 49는 "50에서 1을 뺀 것"이 아니다 — 자릿값(십의 자리 40, 일의 자리 9) 단위로 따로 변환하기 때문이다.

**입출력 예 #2 (`num = 58`)**: 50 = `L`, 8 = `VIII`

**입출력 예 #3 (`num = 1994`)**: 1000 = `M`, 900 = `CM`, 90 = `XC`, 4 = `IV`
