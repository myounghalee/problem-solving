# 피보나치 수

- 문제 번호: 12945
- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/12945
- 분류: 연습문제 (별도 카테고리 태그 없음)

## 문제 설명

피보나치 수는 F(0) = 0, F(1) = 1일 때, 1 이상의 n에 대하여 F(n) = F(n-1) + F(n-2) 가 적용되는 수 입니다.

예를들어

- F(2) = F(0) + F(1) = 1
- F(3) = F(1) + F(2) = 2
- F(4) = F(2) + F(3) = 3
- F(5) = F(3) + F(4) = 5

와 같이 이어집니다.

2 이상의 n이 입력되었을 때, n번째 피보나치 수를 1234567으로 나눈 나머지를 리턴하는 함수, solution을 완성해 주세요.

## 제한사항

- n은 2 이상 100,000 이하인 자연수입니다.

## 함수 시그니처

```java
public int solution(int n)
```

## 입출력 예

| n | return |
|---|---|
| 3 | 2 |
| 5 | 5 |

### 입출력 예 설명

피보나치 수열: 0, 1, 1, 2, 3, 5, ... 이므로 3번째 항은 2, 5번째 항은 5입니다.

## 풀이 아이디어

- 재귀로 짜면 `n ≤ 100,000`에서 시간 초과(지수 시간) — **반드시 반복문(DP) 또는 메모이제이션**으로 풀어야 함.
- 매 단계 `% 1234567` 나머지 연산을 해줘야 오버플로우 없이 끝까지 계산 가능 (n이 커질수록 실제 피보나치 값은 int/long 범위를 훨씬 초과하므로).
- O(n) 시간, O(1) 공간(직전 두 값만 유지)으로 충분히 풀림.
- [멀리 뛰기(12914)](../12914-멀리뛰기/Problem.md)와 점화식이 완전히 동일한 문제(`f(n) = f(n-1) + f(n-2)`) — 함께 비교해서 풀어보면 좋다.
