# 야근 지수

- 문제 번호: 12927
- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/12927
- 분류: 연습문제 (별도 카테고리 태그 없음)

## 문제 설명

회사원 Demi는 가끔은 야근을 하는데요, 야근을 하면 야근 피로도가 쌓입니다. 야근 피로도는 야근을 시작한 시점에서 남은 일의 작업량을 제곱하여 더한 값입니다. Demi는 N시간 동안 야근 피로도를 최소화하도록 일할 겁니다. Demi가 1시간 동안 작업량 1만큼을 처리할 수 있다고 할 때, 퇴근까지 남은 N 시간과 각 일에 대한 작업량 works에 대해 야근 피로도를 최소화한 값을 리턴하는 함수 solution을 완성해주세요.

## 제한사항

- works는 길이 1 이상, 20,000 이하인 배열입니다.
- works의 원소는 50,000 이하인 자연수입니다.
- n은 1,000,000 이하인 자연수입니다.

## 함수 시그니처

```java
public long solution(int n, int[] works)
```

## 입출력 예

| works | n | result |
|---|---|---|
| [4, 3, 3] | 4 | 12 |
| [2, 1, 2] | 1 | 6 |
| [1, 1] | 3 | 0 |

### 입출력 예 설명

**입출력 예 #1**
`n=4`일 때, `[4, 3, 3]`을 4시간 동안 처리하면 `[2, 2, 2]`가 되어 피로도는 `2² + 2² + 2² = 12`.

**입출력 예 #2**
`n=1`일 때, `[2, 1, 2]`를 1시간 동안 처리하면 `[1, 1, 2]`가 되어 피로도는 `1² + 1² + 2² = 6`.

**입출력 예 #3**
남은 작업량이 없으므로(총 작업량 2 ≤ n=3) 피로도는 0입니다.

## 풀이 아이디어

- 매 시간마다 **가장 작업량이 많이 남은 일을 1씩 줄이는 게 항상 최적**이다 — 제곱합을 최소화하려면 값들을 최대한 고르게(분산을 최소로) 만들어야 하는데, 그러려면 매번 가장 큰 값을 깎는 게 유리하다 (볼록함수 성질).
- 매번 "가장 큰 값"을 빠르게 찾고 갱신해야 하므로 **최대 힙(PriorityQueue)** 이 적합.
- `works`의 총합이 `n` 이하라면 전부 처리 가능 → 즉시 0 반환 (예#3).
- 시간복잡도: 최악 `O(n log k)` (n번 반복, 매번 힙 연산 `O(log k)`, k=works.length ≤ 20,000). `n ≤ 1,000,000`이라 상수가 큰 편이니 실제로 통과하는지 확인 필요.
