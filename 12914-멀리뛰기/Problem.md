# 멀리 뛰기

- 문제 번호: 12914
- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/12914
- 분류: 연습문제 (별도 카테고리 태그 없음)

## 문제 설명

효진이는 멀리 뛰기를 연습하고 있습니다. 효진이는 한 번에 1칸, 또는 2칸을 뛸 수 있습니다. 칸이 총 4개 있을 때, 효진이는

- (1칸, 1칸, 1칸, 1칸)
- (1칸, 2칸, 1칸)
- (1칸, 1칸, 2칸)
- (2칸, 1칸, 1칸)
- (2칸, 2칸)

의 5가지 방법으로 맨 끝 칸에 도달할 수 있습니다. 칸의 수 n이 주어질 때, 효진이가 끝에 도달하는 방법이 몇 가지인지 알아내, 여기에 1234567를 나눈 나머지를 리턴하는 함수, solution을 완성하세요.

## 제한사항

- n은 1 이상, 2000 이하인 정수입니다.

## 함수 시그니처

```java
public long solution(int n)
```

## 입출력 예

| n | result |
|---|---|
| 4 | 5 |
| 3 | 3 |

### 입출력 예 설명

**입출력 예 #1**
문제의 예시와 같습니다.

**입출력 예 #2**
칸이 3개일 때는 (2칸, 1칸), (1칸, 2칸), (1칸, 1칸, 1칸)의 3가지 방법이 있습니다.

## 풀이 아이디어

- [피보나치 수(12945)](../12945-피보나치수/Problem.md)와 동일한 점화식 구조: `f(n) = f(n-1) + f(n-2)` — 마지막 점프가 1칸이었는지 2칸이었는지로 경우를 나누면 그대로 피보나치 점화식이 나온다.
- 반환 타입이 `long`인 이유: 문제에서 나머지를 취하기 전 값은 int 범위를 넘을 수 있어서(비록 매 단계 `% 1234567`로 나머지를 취하면 int로도 충분하지만, 시그니처 자체가 long).
- 12945와 마찬가지로 O(n) 반복 + 매 단계 나머지 연산으로 처리.
