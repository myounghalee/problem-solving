# H-Index

- 문제 번호: 42747
- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/42747
- 분류: 정렬 (Sorting)

## 문제 설명

H-Index는 과학자의 생산성과 영향력을 나타내는 지표입니다. 어떤 과학자가 발표한 논문 `n`편 중, `h`번 이상 인용된 논문이 `h`편 이상이고 나머지 논문이 `h`번 이하 인용되었다면 `h`의 최댓값이 이 과학자의 H-Index입니다.

어떤 과학자가 발표한 논문의 인용 횟수를 담은 배열 citations가 매개변수로 주어질 때, 이 과학자의 H-Index를 return 하도록 solution 함수를 완성하세요.

## 제한사항

- 과학자가 발표한 논문의 수는 1편 이상 1,000편 이하입니다.
- 논문별 인용 횟수는 0회 이상 10,000회 이하입니다.

## 함수 시그니처

```java
public int solution(int[] citations)
```

## 입출력 예

| citations | return |
|---|---|
| [3, 0, 6, 1, 5] | 3 |

### 입출력 예 설명

이 과학자가 발표한 논문의 수는 5편이고, 인용 횟수는 각각 3, 0, 6, 1, 5회입니다. 이 중 3편의 논문은 3회 이상 인용되었습니다. 그리고 나머지 2편의 논문은 3회 이하 인용되었기 때문에 이 과학자의 H-Index는 3입니다.

## 풀이 아이디어

- `citations`를 **내림차순**으로 정렬하면, 앞에서부터 `i`번째(0-indexed)까지가 "인용 횟수가 `i+1`번째로 많은 논문들"이 된다.
- 정렬된 배열을 순회하며 각 인덱스 `i`에서 "지금까지 본 논문 수(`i+1`)"와 "그 논문의 인용 횟수(`citations[i]`)"를 비교 — `citations[i] >= i+1`을 만족하는 마지막 지점을 찾으면 그게 H-Index의 후보.
- 정렬 O(n log n) + 순회 O(n)으로 충분. `n ≤ 1,000`이라 훨씬 단순한 방법(모든 h값을 브루트포스로 시도)도 통과할 여지가 있음 — 두 방식을 비교해볼 것.
