# [프로그래머스 87694] 아이템 줍기 — 좌표 2배 확장 + BFS로 풀기

- 문제 번호: 87694
- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/87694
- 분류: 깊이/너비 우선 탐색(DFS/BFS)
- 사용 자료구조/알고리즘: **좌표 확장(스케일링) + BFS**
- 난이도 체감: Lv.2 (BFS 자체는 단순하지만, "왜 좌표를 2배로 늘려야 하는지"를 이해하는 게 핵심)

## 1. 문제 요약

여러 직사각형이 겹쳐서 만들어진 다각형 지형이 있다. 캐릭터는 이 다각형의 **가장 바깥쪽 테두리**만 따라 이동할 수 있다. 캐릭터 위치에서 아이템 위치까지, 테두리를 따라 이동하는 최단 거리를 구한다.

```text
예시) rectangle = [[1,1,7,4],[3,2,5,5],[4,3,6,9],[2,6,8,8]]
      character(1,3) → item(7,8), 테두리를 따라가면 최단 거리 17
```

**제한사항**
- 직사각형 개수: 1 ~ 4개, 좌표값은 1 ~ 50
- 서로 다른 두 직사각형은 x좌표·y좌표가 절대 겹치지 않음(꼭짓점에서 만나거나 변이 겹치는 경우 없음)
- 지형은 항상 하나로 연결되어 있고, 한 사각형이 다른 사각형에 완전히 포함되는 경우도 없음
- 캐릭터·아이템 위치는 항상 테두리 위의 한 점

## 2. 접근 아이디어

큰 그림은 단순하다: **격자에 "테두리인 칸"을 표시해두고, 그 칸들만 따라 BFS로 최단 거리를 구하면 된다.** 테두리를 만드는 방법도 직관적이다.

1. 모든 직사각형의 네 변에 해당하는 칸을 전부 `true`(테두리)로 표시한다.
2. 그다음, 각 직사각형의 **순수 내부(변 제외)** 칸들을 전부 `false`로 되돌린다. 여러 직사각형이 겹쳐서 생긴 내부 공간은 이렇게 하면 자동으로 지워지고, 가장 바깥쪽 윤곽선만 `true`로 남는다.
3. 캐릭터 위치에서 시작해 `true`인 칸들만 상하좌우로 이동하는 BFS를 돌려 아이템 위치까지의 최단 거리를 구한다.

### 왜 좌표를 그대로 안 쓰고 2배로 늘리는가

이 문제의 핵심 함정이다. 좌표를 원래 정수 그대로 쓰면, 서로 다른 두 직사각형의 변이 아주 가까이 붙어 있을 때(테두리 칸 사이의 "폭"이 1칸밖에 안 될 때) 실제 다각형 모양상 막혀 있어야 할 지점을, 2단계(내부 지우기)에서 다른 사각형의 진짜 테두리 칸까지 같이 지워버리는 문제가 생길 수 있다.

**좌표를 2배로 확장하면** 원래 정수 좌표 사이사이에 여분의 칸이 하나씩 더 생긴다. 그 여유 공간 덕분에, "이 칸이 어떤 사각형의 순수 내부인지"와 "이 칸이 다른 사각형의 진짜 테두리인지"를 헷갈리지 않고 정확히 구분할 수 있다. 대신 좌표를 2배로 늘렸으니, 최종 이동 거리도 2배로 세어지므로 **답을 반환할 때 2로 나눠줘야** 실제 거리가 나온다.

## 3. 코드 (Java)

```java
import java.util.*;

class Solution {
    public int solution(int[][] rectangle, int characterX, int characterY, int itemX, int itemY) {
        int maxX = 0, maxY = 0;
        for (int[] rect : rectangle) {
            maxX = Math.max(maxX, rect[2]) * 2;
            maxY = Math.max(maxY, rect[3]) * 2;
        }

        boolean[][] border = new boolean[maxX + 1][maxY + 1]; // 좌표를 2배로 확장한 격자 위의 테두리 표시

        // 1단계: 모든 직사각형의 네 변을 테두리(true)로 표시
        for (int[] rect : rectangle) {
            int x1 = rect[0] * 2, y1 = rect[1] * 2, x2 = rect[2] * 2, y2 = rect[3] * 2;
            for (int x = x1; x <= x2; x++) {
                border[x][y1] = true;
                border[x][y2] = true;
            }
            for (int y = y1; y <= y2; y++) {
                border[x1][y] = true;
                border[x2][y] = true;
            }
        }

        // 2단계: 각 직사각형의 "순수 내부"(변 제외)는 테두리에서 지움
        for (int[] rect : rectangle) {
            int x1 = rect[0] * 2, y1 = rect[1] * 2, x2 = rect[2] * 2, y2 = rect[3] * 2;
            for (int x = x1 + 1; x < x2; x++) {
                for (int y = y1 + 1; y < y2; y++) {
                    border[x][y] = false;
                }
            }
        }

        // 3단계: 남은 테두리(border == true)만 따라 BFS로 최단 거리 탐색
        int[] dx = {-1, 1, 0, 0}, dy = {0, 0, -1, 1};
        boolean[][] visited = new boolean[maxX + 1][maxY + 1];
        Deque<int[]> queue = new ArrayDeque<>();
        queue.add(new int[]{characterX * 2, characterY * 2, 0});
        visited[characterX * 2][characterY * 2] = true;

        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            int x = cur[0], y = cur[1], dist = cur[2];
            if (x == itemX * 2 && y == itemY * 2) return dist / 2; // 2배로 늘렸던 걸 다시 절반으로

            for (int i = 0; i < 4; i++) {
                int nx = x + dx[i], ny = y + dy[i];
                if (nx < 0 || ny < 0 || nx > maxX || ny > maxY) continue;
                if (!border[nx][ny] || visited[nx][ny]) continue;
                visited[nx][ny] = true;
                queue.add(new int[]{nx, ny, dist + 1});
            }
        }

        return 0; // 문제 조건상 항상 경로가 존재하므로 이 지점에 도달하지 않음
    }
}
```

### 코드 설명

- `maxX`, `maxY`는 모든 직사각형 좌표 중 가장 큰 값을 2배로 잡아서, `border`/`visited` 격자의 크기를 결정한다.
- 1단계 루프는 각 직사각형의 좌측 하단(`x1,y1`)~우측 상단(`x2,y2`)을 이용해 네 변에 해당하는 칸을 전부 `true`로 켠다.
- 2단계 루프는 `x1+1`부터 `x2-1`까지(변은 제외한 순수 내부)만 순회하며 `false`로 지운다. 이 순서(먼저 다 켜고 나중에 내부만 끄기) 덕분에, 여러 직사각형이 겹쳐서 생긴 안쪽 공간은 자동으로 지워지고 가장 바깥 윤곽선만 남는다.
- BFS는 일반적인 격자 BFS와 동일하다. `dist`는 2배로 확장된 격자 위에서 이동한 칸 수이므로, 아이템에 도착했을 때 `dist / 2`로 실제 거리를 돌려준다.

## 4. 복잡도 분석

- **시간복잡도**: `O(maxX × maxY)` — 격자 크기가 좌표 최댓값의 2배(최대 100×100)이고, 테두리 표시·내부 지우기·BFS 모두 격자 칸 수에 비례한다. 좌표 제한이 최대 50이라 `100 × 100 = 10,000` 수준으로 충분히 빠르다.
- **공간복잡도**: `O(maxX × maxY)` — `border`, `visited` 두 개의 2차원 배열.

## 5. 엣지 케이스

- **직사각형이 1개뿐인 경우** (예시 3): 겹침이 없으니 내부 지우기 단계에서 그 사각형 하나의 안쪽만 지워지고, 나머지 테두리(사각형 둘레 전체)가 그대로 이동 경로가 된다.
- **직사각형이 여러 개 겹쳐 복잡한 다각형을 이루는 경우**: "모든 변을 켠 뒤, 각자의 순수 내부만 끈다"는 순서 덕분에, 서로 다른 사각형이 겹치며 생기는 내부 공간도 자연스럽게 하나씩 지워지고 최종적으로 가장 바깥 윤곽선만 남는다.
- **좌표를 2배로 안 늘렸다면**: 서로 매우 가깝게 배치된 두 사각형 사이에서 내부 지우기 단계가 다른 사각형의 진짜 테두리까지 잘못 지워버릴 수 있다. 2배 확장이 이 문제를 근본적으로 방지한다.
