# 가장 먼 노드

- 문제 번호: 49189
- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/49189
- 분류: 그래프

## 문제 설명

n개의 노드가 있는 그래프가 있습니다. 각 노드는 1부터 n까지 번호가 적혀있습니다. 1번 노드에서 가장 멀리 떨어진 노드의 갯수를 구하려고 합니다. 가장 멀리 떨어진 노드란 최단경로로 이동했을 때 간선의 개수가 가장 많은 노드들을 의미합니다.

노드의 개수 n, 간선에 대한 정보가 담긴 2차원 배열 vertex가 매개변수로 주어질 때, 1번 노드로부터 가장 멀리 떨어진 노드가 몇 개인지를 return 하도록 solution 함수를 작성해주세요.

## 제한사항

- 노드의 개수 n은 2 이상 20,000 이하입니다.
- 간선은 양방향이며 총 1개 이상 50,000개 이하의 간선이 있습니다.
- vertex 배열 각 행 [a, b]는 a번 노드와 b번 노드 사이에 간선이 있다는 의미입니다.

## 함수 시그니처

```java
public int solution(int n, int[][] edge)
```

## 입출력 예

| n | vertex | return |
|---|---|---|
| 6 | [[3, 6], [4, 3], [3, 2], [1, 3], [1, 2], [2, 4], [5, 2]] | 3 |

### 입출력 예 설명

예제의 그래프를 표현하면, 1번 노드에서 가장 멀리 떨어진 노드는 4, 5, 6번 노드입니다.

## 풀이 아이디어

- 모든 간선의 가중치가 1인 무방향 그래프에서 "1번 노드로부터의 최단 거리"를 구하는 문제이므로 **BFS**로 O(n + m)에 풀 수 있다.
- 인접 리스트를 구성하고, 1번 노드부터 BFS로 각 노드까지의 최단 거리(간선 개수)를 구한다.
- 구해진 거리 배열에서 최댓값을 찾고, 그 최댓값과 같은 거리를 가진 노드의 개수를 센다.
