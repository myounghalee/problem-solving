# [프로그래머스 49189] 가장 먼 노드 — BFS로 풀기

- 문제 번호: 49189
- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/49189
- 분류: 그래프
- 사용 자료구조/알고리즘: **BFS (너비 우선 탐색)**
- 난이도 체감: Lv.3 (BFS로 최단 거리를 구하는 기본기만 있으면 어렵지 않음)

## 1. 문제 요약

`n`개의 노드(1번 ~ `n`번)로 이루어진 무방향 그래프가 주어진다. 1번 노드에서 각 노드까지의 **최단 거리(간선 개수)**를 구했을 때, 그 최단 거리가 가장 큰 노드가 몇 개인지 반환한다.

```text
예시) n = 6, edge = [[3,6],[4,3],[3,2],[1,3],[1,2],[2,4],[5,2]]
1번 노드로부터 가장 멀리 떨어진 노드: 4, 5, 6번 (거리 2) → 3개
```

**제한사항**
- 노드 개수: 2 ≤ n ≤ 20,000
- 간선 개수: 1 ≤ 간선 수 ≤ 50,000
- 간선은 양방향

## 2. 접근 아이디어 — 왜 BFS인가

모든 간선의 가중치가 1인 무방향 그래프에서 "특정 노드로부터 다른 모든 노드까지의 최단 거리"를 구하는 문제는 **BFS**의 전형적인 활용이다. 가중치가 없기 때문에 다익스트라 같은 우선순위 큐 기반 알고리즘 없이도, BFS로 큐에서 꺼내는 순서 자체가 곧 거리 순서가 된다(레벨 단위로 퍼져나가므로).

- 인접 리스트로 그래프를 구성한다.
- 1번 노드에서 시작해 BFS를 돌리며, 각 노드를 처음 방문할 때의 깊이(간선 개수)를 거리로 기록한다.
- 모든 노드의 거리를 구한 뒤, 그중 최댓값을 찾고 그 값과 같은 거리를 가진 노드 개수를 센다.

### 손으로 시뮬레이션 — `n=6, edge=[[3,6],[4,3],[3,2],[1,3],[1,2],[2,4],[5,2]]`

인접 리스트: `1:[3,2]`, `2:[3,1,4,5]`, `3:[6,4,2,1]`, `4:[3,2]`, `5:[2]`, `6:[3]`

| 단계 | 큐 | 방문/거리 갱신 |
|---|---|---|
| 시작 | `[1]` | `dist[1]=0` |
| 1 pop | `[]` → `[3,2]` | `dist[3]=1`, `dist[2]=1` |
| 3 pop | `[2]` → `[2,6,4]` | `dist[6]=2`, `dist[4]=2` (1은 이미 방문) |
| 2 pop | `[6,4]` → `[6,4,5]` | `dist[5]=2` (3,1,4는 이미 방문/방문 예정) |
| 6,4,5 pop | `[]` | 더 이상 새로 방문할 노드 없음 |

결과 `dist = [-, 0, 1, 1, 2, 2, 2]` (인덱스 1~6). 최댓값은 `2`이고, 거리 2인 노드는 `4, 5, 6` → 정답 `3`.

## 3. 코드 (Java)

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Arrays;
import java.util.Deque;
import java.util.List;

class Solution {
    public int solution(int n, int[][] edge) {
        List<List<Integer>> graph = new ArrayList<>(); // 인접 리스트 (graph.get(i) = i와 연결된 노드 목록)
        for (int i = 0; i <= n; i++) {
            graph.add(new ArrayList<>());
        }
        for (int[] e : edge) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]); // 양방향이므로 역방향도 추가
        }

        int[] dist = new int[n + 1]; // 1번 노드로부터의 최단 거리, -1은 미방문
        Arrays.fill(dist, -1);
        dist[1] = 0;

        Deque<Integer> queue = new ArrayDeque<>(); // BFS 큐
        queue.offer(1);
        while (!queue.isEmpty()) {
            int cur = queue.poll();
            for (int next : graph.get(cur)) {
                if (dist[next] == -1) {
                    dist[next] = dist[cur] + 1;
                    queue.offer(next);
                }
            }
        }

        int maxDist = 0; // 전체 노드 중 최단 거리의 최댓값
        for (int i = 1; i <= n; i++) {
            maxDist = Math.max(maxDist, dist[i]);
        }

        int answer = 0; // 최댓값과 거리가 같은 노드 개수
        for (int i = 1; i <= n; i++) {
            if (dist[i] == maxDist) {
                answer++;
            }
        }
        return answer;
    }
}
```

### 코드 설명

- `graph`는 인접 리스트로, `n+1` 크기로 만들어 노드 번호(1-indexed)를 배열 인덱스에 그대로 대응시켰다(0번 인덱스는 안 씀).
- BFS는 `ArrayDeque`를 큐로 사용한다. 방문 여부와 거리를 `dist` 배열 하나로 겸용했다 — `dist[i] == -1`이면 아직 미방문, 아니면 그 값이 곧 1번 노드로부터의 거리다.
- BFS 특성상 큐에서 꺼내는 순서가 거리 오름차순이므로, 어떤 노드를 처음 발견하는 순간의 거리가 곧 최단 거리임이 보장된다 (별도의 최소값 비교가 필요 없다).
- 마지막에 `dist` 배열을 두 번 순회해 최댓값을 구하고, 그 최댓값과 같은 노드 수를 센다.

## 4. 복잡도 분석

- **시간복잡도**: `O(n + m)` — 인접 리스트 구성에 `O(m)`, BFS 순회에 `O(n + m)` (`n`은 노드 수, `m`은 간선 수).
- **공간복잡도**: `O(n + m)` — 인접 리스트와 거리 배열, 큐가 차지하는 공간.

`n ≤ 20,000`, 간선 ≤ 50,000 제한에서 `O(n + m)` BFS로 충분히 빠르게 통과한다.

## 5. 엣지 케이스

- 그래프가 트리 형태(간선 수 = n-1)인 경우도 동일하게 동작한다 — BFS는 사이클 유무와 무관하게 최단 거리를 구한다.
- 1번 노드와 직접 연결된 노드가 하나뿐이어도, 그 뒤로 체인처럼 이어지는 구조라면 가장 먼 노드가 1개일 수도 있다.
- 문제 제약상 그래프는 연결되어 있다고 보장되므로(간선이 1개 이상, `n ≥ 2`), 모든 노드가 `dist != -1`로 채워짐을 가정해도 된다.
