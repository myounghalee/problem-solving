# 연속 펄스 부분 수열의 합

- 문제 번호: 161988
- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/161988
- 분류: 연습문제 (별도 카테고리 태그 없음)

## 문제 설명

어떤 수열의 연속 부분 수열에 같은 길이의 펄스 수열을 각 원소끼리 곱하여 연속 펄스 부분 수열을 만들려 합니다. 펄스 수열이란 [1, -1, 1, -1 …] 또는 [-1, 1, -1, 1 …] 과 같이 1 또는 -1로 시작하면서 1과 -1이 번갈아 나오는 수열입니다.

예를 들어 수열 [2, 3, -6, 1, 3, -1, 2, 4]의 연속 부분 수열 [3, -6, 1]에 펄스 수열 [1, -1, 1]을 곱하면 연속 펄스 부분수열은 [3, 6, 1]이 됩니다. 또 다른 예시로 연속 부분 수열 [3, -1, 2, 4]에 펄스 수열 [-1, 1, -1, 1]을 곱하면 연속 펄스 부분수열은 [-3, -1, -2, 4]이 됩니다.

정수 수열 `sequence`가 매개변수로 주어질 때, 연속 펄스 부분 수열의 합 중 가장 큰 것을 return 하도록 solution 함수를 완성해주세요.

## 제한 사항

- 1 ≤ `sequence`의 길이 ≤ 500,000
- -100,000 ≤ `sequence`의 원소 ≤ 100,000
  - `sequence`의 원소는 정수입니다.

## 함수 시그니처

```java
public long solution(int[] sequence)
```

**매개변수 설명**

| 매개변수 | 의미 |
|---|---|
| `sequence` | 정수 수열 |

**반환값**: 연속 펄스 부분 수열의 합 중 최댓값 (`long`)

## 입출력 예

| sequence | result |
|---|---|
| [2, 3, -6, 1, 3, -1, 2, 4] | 10 |

### 입출력 예 설명

주어진 수열의 연속 부분 수열 [3, -6, 1]에 펄스 수열 [1, -1, 1]을 곱하여 연속 펄스 부분 수열 [3, 6, 1]을 얻을 수 있고 그 합은 10으로서 가장 큽니다.

## 풀이 아이디어

- 펄스를 직접 곱하는 대신, `A[i] = sequence[i] * (i가 짝수면 1, 홀수면 -1)`로 미리 변환해두면, **연속 부분 수열의 펄스합**은 `A`의 연속 부분 구간 합에 부호(`±1`)만 붙인 것과 같아진다 — 즉 이 문제는 결국 **최대 부분 배열 합(Kadane's Algorithm)** 문제로 환원된다.
- 펄스가 `[1,-1,1,...]`로 시작하는 경우와 `[-1,1,-1,...]`로 시작하는 경우 둘 다 고려해야 하므로, `A`의 **최대 부분 배열 합**과 `A`의 **최소 부분 배열 합(부호를 뒤집으면 최대가 됨)** 중 더 큰 값을 답으로 한다.
- `sequence.length ≤ 500,000`이라 Kadane's Algorithm(`O(n)`)이 아니면 시간 초과 위험이 크다. 반환 타입이 `long`인 이유도 값의 범위(최대 `100,000 × 500,000`)가 `int`를 넘을 수 있어서다.
