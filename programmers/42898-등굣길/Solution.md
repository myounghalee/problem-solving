# [프로그래머스 42898] 등굣길 — 격자 DP, 좌표 순서를 조심할 것

- 문제 번호: 42898
- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/42898
- 분류: 동적계획법(Dynamic Programming)
- 사용 자료구조/알고리즘: **격자 DP**
- 난이도 체감: Lv.2 (DP 자체는 표준적, `(x,y)` 좌표를 배열 인덱스로 옮길 때 순서 실수가 나오기 쉬움)

## 1. 문제 요약

`m × n` 격자에서 `(1,1)`(집)부터 `(m,n)`(학교)까지 **오른쪽/아래로만** 이동하는 최단경로의 개수를, 물웅덩이(`puddles`) 칸을 지나지 않으면서 구한다. 답은 `1,000,000,007`로 나눈 나머지.

```text
m=4, n=3, puddles=[[2,2]] → 4
```

**제한사항**: `m, n` 1~100 (둘 다 1인 경우는 없음), 물웅덩이 0~10개.

## 2. 접근 아이디어 — 표준 격자 경로 DP

`dp[y][x]` = "집(1,1)에서 `(x,y)`까지 오는 최단경로의 수"라 하면:

```
dp[y][x] = dp[y-1][x] + dp[y][x-1]   (위에서 오거나, 왼쪽에서 오거나)
```

물웅덩이 칸은 `dp[y][x] = 0`으로 고정한다 (그 칸을 지나는 경로 자체가 없으므로, 이후 계산에서도 자동으로 `0`이 전파되어 그쪽을 거치는 경로는 전부 제외된다). 기저 조건은 `dp[0][0] = 1`(집 자체, 시작점).

### 배열 인덱스와 `(x, y)` 좌표를 맞출 때 조심할 점

`m`은 가로 크기, `n`은 세로 크기다. 배열을 `dp[n][m]`(행 `n`개, 열 `m`개)로 잡으면, **행 인덱스는 `y`, 열 인덱스는 `x`에 대응**해야 한다. 즉 좌표 `(x, y)`인 칸은 `dp[y-1][x-1]`이지, `dp[x-1][y-1]`이 아니다 — `puddles`의 원소가 `[x, y]` 순서로 주어지기 때문에 이 부분에서 순서를 뒤집기 쉽다.

### 손으로 시뮬레이션 — `m=4, n=3, puddles=[[2,2]]`

`dp`를 전부 1로 채운 뒤 `(2,2)`(0-indexed `dp[1][1]`)를 `0`으로 막고 채워나간다.

| y\x | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| 1 | 1 | 1 | 1 | 1 |
| 2 | 1 | **0**(웅덩이) | 1 | 2 |
| 3 | 1 | 1 | 2 | 4 |

`dp[3][4] = 4`. 정답과 일치.

## 3. 코드 (Java)

```java
import java.util.Arrays;

class Solution {
    private static final int MOD = 1_000_000_007;

    public int solution(int m, int n, int[][] puddles) {
        int[][] dp = new int[n][m];
        for (int[] row : dp) Arrays.fill(row, 1);

        for (int[] p : puddles) {
            dp[p[1] - 1][p[0] - 1] = 0; // p = [x, y] -> dp[y-1][x-1]
        }

        for (int y = 0; y < n; y++) {
            for (int x = 0; x < m; x++) {
                if (y == 0 && x == 0) continue;
                if (dp[y][x] == 0) continue;

                int fromUp = (y == 0) ? 0 : dp[y - 1][x];
                int fromLeft = (x == 0) ? 0 : dp[y][x - 1];
                dp[y][x] = (fromUp + fromLeft) % MOD;
            }
        }

        return dp[n - 1][m - 1];
    }
}
```

### 코드 설명

- `dp[n][m]`으로 선언하고 전부 `1`로 초기화한 뒤, 물웅덩이 칸만 `0`으로 덮어쓴다.
- `puddles`의 `p = [x, y]`를 `dp[p[1]-1][p[0]-1]`(= `dp[y-1][x-1]`)로 뒤집어서 대입하는 게 핵심 — 배열의 행이 `y`, 열이 `x`이기 때문.
- 이미 `0`(웅덩이)인 칸은 `continue`로 건너뛰어 계산하지 않는다 — 그대로 `0`이 유지되어야 "그 칸을 지나는 경로 없음"이 다음 칸들로 올바르게 전파된다.
- 매 칸마다 `% MOD`를 적용한다 (`m,n≤100`이라 오버플로우 위험은 거의 없지만 습관적으로 안전하게).

## 4. 복잡도 분석

- **시간복잡도**: `O(m × n)` — 격자를 한 번만 순회.
- **공간복잡도**: `O(m × n)` — `dp` 배열.

`m, n ≤ 100`이라 최대 10,000칸뿐이라 사실상 즉시 끝난다. 실측(`m=n=100`, 웅덩이 10개): **약 0.05ms**.

## 5. 검증

`m, n ≤ 6`인 작은 격자에서 **모든 경로를 완전탐색(DFS)** 하는 참조 구현과 2,000회 무작위 비교(물웅덩이 0~2개, 무작위 위치)해서 전부 일치함을 확인했다. 공식 예시도 통과한다.

## 6. 엣지 케이스

- 물웅덩이가 하나도 없는 경우: 순수 조합 문제와 동일 (`C(m+n-2, m-1)`과 같은 값이 DP로 자연스럽게 나온다).
- 물웅덩이가 시작/도착 지점을 완전히 가로막는 경우(예: 첫 행이나 첫 열 전체를 덮는 배치): 도착 칸까지 `dp` 값이 `0`으로 전파되어 정답이 `0`이 된다.
- 직사각형(`m ≠ n`) 격자: 좌표 순서를 뒤집는 부분(`dp[p[1]-1][p[0]-1]`)을 정사각 격자로만 테스트하면 실수해도 못 알아챌 수 있어서, 직사각 격자로도 꼭 검증할 것.
