# 등굣길

- 문제 번호: 42898
- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/42898
- 분류: 동적계획법(Dynamic Programming)

## 문제 설명

계속되는 폭우로 일부 지역이 물에 잠겼습니다. 물에 잠기지 않은 지역을 통해 학교를 가려고 합니다. 집에서 학교까지 가는 길은 m x n 크기의 격자모양으로 나타낼 수 있습니다.

아래 그림은 m = 4, n = 3 인 경우입니다.

가장 왼쪽 위, 즉 집이 있는 곳의 좌표는 (1, 1)로 나타내고 가장 오른쪽 아래, 즉 학교가 있는 곳의 좌표는 (m, n)으로 나타냅니다.

격자의 크기 m, n과 물이 잠긴 지역의 좌표를 담은 2차원 배열 puddles이 매개변수로 주어집니다. **오른쪽과 아래쪽으로만 움직여** 집에서 학교까지 갈 수 있는 최단경로의 개수를 1,000,000,007로 나눈 나머지를 return 하도록 solution 함수를 작성해주세요.

## 제한사항

- 격자의 크기 m, n은 1 이상 100 이하인 자연수입니다.
  - m과 n이 모두 1인 경우는 입력으로 주어지지 않습니다.
- 물에 잠긴 지역은 0개 이상 10개 이하입니다.
- 집과 학교가 물에 잠긴 경우는 입력으로 주어지지 않습니다.

## 함수 시그니처

```java
public int solution(int m, int n, int[][] puddles)
```

**매개변수 설명**

| 매개변수 | 의미 |
|---|---|
| `m` | 격자의 가로 크기 (집~학교의 x좌표 범위, 1~m) |
| `n` | 격자의 세로 크기 (집~학교의 y좌표 범위, 1~n) |
| `puddles` | 물에 잠긴 지역들의 좌표 `[x, y]` 배열 |

**반환값**: 최단경로 개수를 1,000,000,007로 나눈 나머지

## 입출력 예

| m | n | puddles | return |
|---|---|---|---|
| 4 | 3 | [[2, 2]] | 4 |

### 입출력 예 설명

주어진 예제에서 물에 잠긴 지역이 (2, 2)일 때, 집에서 학교까지 갈 수 있는 경로의 개수는 4입니다.

## 풀이 아이디어

- 전형적인 "격자에서 오른쪽/아래로만 이동하는 최단경로 수" DP: `dp[x][y] = dp[x-1][y] + dp[x][y-1]` (왼쪽에서 오거나 위에서 오는 경로의 합).
- 물에 잠긴 칸은 `dp[x][y] = 0`으로 고정 — 그 칸을 지나는 경로는 존재하지 않으므로.
- `dp[1][1] = 1`(집 자체, 시작점)로 기저 조건을 잡고 왼쪽 위부터 채워나간다.
- 좌표 순서(`m`이 x, `n`이 y인지)를 문제 그림과 정확히 맞추는 게 헷갈리기 쉬운 지점 — `puddles`의 좌표 `[x, y]`가 `(가로, 세로)` 순서임에 유의.
- `1,000,000,007`로 매 단계 나머지를 취해야 함 (m, n ≤ 100이라 오버플로우 위험은 크지 않지만 습관적으로).
- [땅따먹기(12913)](../12913-땅따먹기/Solution.md)와 같은 "격자 위에서 DP" 계열 문제 — 다만 그쪽은 열 이동에 제약(같은 열 연속 금지)이 있었고, 이 문제는 장애물(물 웅덩이) 칸을 0으로 막는 방식이라 차이가 있다.
